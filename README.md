# FB Scroll App 📱

Facebook content scrolling and browsing application.

## ✨ Features

- 📜 Infinite scroll
- 🔄 Pull to refresh
- ❤️ Like and reactions
- 💬 Comment viewing
- 📤 Share functionality

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/antono4/fb-scroll-app.git

# Open in browser
cd fb-scroll-app
open index.html
```

## 📁 Project Structure

```
fb-scroll-app/
├── index.html      # Main page
├── css/            # Stylesheets
├── js/             # JavaScript files
└── assets/         # Static assets
```
